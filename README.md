# Pop

AI assistant for macOS equipped with computer-use and browser-use skills.

Pop is a floating assistant — a mascot panel with a composer that can see and operate your screen: on-device AX-tree perception, screen reading, real pointer/keyboard actuation, an embedded browser controller, and a native jev decision engine (measured-strength step gating, typed exits, per-step audit) driving computer-use and browser-use actions with approval gating.

## Download

Grab the latest signed build from [Releases](https://github.com/kianwoon/pop/releases). Requires macOS with Accessibility + Screen Recording permission grants on first launch.
